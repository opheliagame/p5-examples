# 🌸 opheliagame's p5.js sketches 🌸

A collection of p5 sketches, functions and utilities

## Getting started

Use this as `index.html` to start using the custom functions defined in `lib`

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.11.8/p5.js"></script>
    <script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.11.8/addons/p5.sound.min.js"></script>
    <link rel="stylesheet" type="text/css" href="/style.css" />
    <meta charset="utf-8" />

    <!-- LIB -->
    <script src="https://raw.githubusercontent.com/opheliagame/p5-examples/refs/heads/main/dist/op-cc.js"></script>
  </head>
  <body>
    <main></main>
    <script src="sketch.js"></script>
  </body>
</html>
```
